# Omni v1.0.3

可以直接覆盖安装 1.0.0–1.0.2，不用卸载，会话、模型配置和插件都会保留。

## 新功能

- **扩展市场**：设置里新增「扩展」，两个 tab。
  - 技能：先看你已经装的，再逛市场。技能只是一份说明文件，装上立刻生效、不用重启；内置的技能不能删，自己装的可以卸载。
  - 插件：可以直接浏览市场里适配手机的插件并安装，装完提示重启引擎。
  - 首批技能有 4 个：生成规范提交说明、处理 Word 文档（Anthropic 官方）、明确目标与截图（OpenAI 官方）。
- **更新入口改到界面上**：设置里的「应用更新」不再显示。发现新版本时，右下角会出现「有可用更新」按钮，左抽屉底部「更多」也会点亮一个小标记，点一下就能下载安装。

## 之前版本的改动（一并包含）

- 启动页重做：竖排居中、真实进度与剩余时间。
- 首次解压改为多线程并行，明显更快。
- 隐藏了设置里的「订阅」入口。

## 已知情况

- 「手机控制」入口仍处于冻结状态，无障碍权限需要到系统设置里手动开启。
- 技能市场是在手机上直接访问 GitHub 下载文件，网络不通时会显示具体的失败原因。

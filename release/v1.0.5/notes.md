# Omni v1.0.5

可以直接覆盖安装，数据都会保留。

## 扩展市场

- 市场里现在有 7 个技能：
  - **淘宝 App 购物**：在手机淘宝/天猫里搜索、比价、看详情、加购物车。下单和付款前一定会先问你。
  - **图片风格改写**、**图片整理清单**：前者写图像工具的提示词，后者给修图检查清单。
  - **Word 文档（docx）**、**定义目标**、**截图**、**Git 提交说明**。
- 已安装的技能如果有更新，会显示「可更新」，点一下就地更新。
- 网络不通时自动改用镜像；仍然不行就显示上次保存的清单，并注明日期。

## 之前版本的修复

- 右下角不再在没有新版本时显示按钮。
- 点抽屉里的更新按钮不会再跳回主页面。

# Omni v1.0.7

可以直接覆盖安装，数据都会保留。

## 淘宝技能现在能直接用

- 之前用淘宝技能会卡在「只开放了虚拟屏」：淘宝装在真实屏幕上，而默认的屏幕范围是「仅虚拟屏幕」，
  设置里的「手机控制」页又是收起的，提示让人去找一个找不到的入口。
- 现在淘宝技能会把自己的能力要求写清楚：**需要无障碍 + 需要真实屏幕**。缺哪项就在扩展页对应行
  显示提示，并给出按钮：
  - 「去开启」跳到系统无障碍设置；
  - 「允许真实屏幕」在本页直接把屏幕范围放开（改为 all），点一下即可，不需要再找设置页。
- 已安装的淘宝技能如果还缺某项，也会在「设置 → 扩展 → 技能」里显示同样的提示。
- 设备工具被屏幕范围拦下时，报错会直接告诉你：去「设置 → 扩展 → 技能」，在该技能行点「允许」。

## 之前版本的内容

- 淘宝/天猫里提交订单、付款、退款等按钮由设备层拦截，按文字点和按坐标点都一样。

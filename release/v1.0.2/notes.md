# Omni v1.0.2

可以直接覆盖安装 1.0.0 / 1.0.1，不用卸载，会话、模型配置和插件都会保留。

## 改动

- **启动页重做**：图标、应用名、说明竖排居中；进度、百分比和剩余时间并成一行；解压期间不再显示日志和诊断入口，底部按钮也不再是整屏的大灰块。
- **首次打开更快**：快照改为多线程并行解压，测试机上解码时间约 7 秒降到约 2 秒，整体解压缩短约四成。
- **设置更简洁**：隐藏「订阅」入口；「手机控制」入口暂时冻结，AI 的手机操作能力不受影响。

## 已知情况

- 「手机控制」冻结期间，无障碍权限需要到系统设置里手动开启。
- 技能市场的服务端已经打进本体，界面还在做，这一版设置里暂时看不到入口。

# Omni v1.0.8

可以直接覆盖安装，数据都会保留。

## 真实屏幕不再需要额外设置

- 以前「屏幕范围」缺省是「仅虚拟屏」，而淘宝这类技能必须在真实屏幕上操作，装好也不能用；
  设置里的「手机控制」页又收起了，用户找不到开关。
- 现在**从未设置过屏幕范围时默认允许真实屏幕**（淘宝等技能开箱可用）。如果之前明确选过
  「仅虚拟屏」，或者落盘值损坏，仍然按原值/保守值处理。
- 扩展页顶部会在「仅虚拟屏」时给一个提示和「允许真实屏幕」按钮，点一下即可放开，不再依赖
  市场清单是否拉取成功。

## 淘宝技能

- 技能会声明「需要无障碍 + 需要真实屏幕」，缺哪项就在对应行提示并给开启入口。
- 提交订单、付款、退款这类按钮仍由设备层硬拦截，不会被 AI 自动执行。
